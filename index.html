原理

三步，句子就变了样

不用换键盘、不用装输入法。你照常打字，剩下交给悬浮球——或切到篡改键盘 / 断句追加 / 摇一摇模式全自动。

  1. 01

    正常打字

    在任意输入框里像平时一样输入文本。即时通讯、社交、笔记——悬浮球不依赖特定应用，全局可用。

  2. 02

    触发变换

    四种模式任选：点悬浮球改写发送、篡改键盘模式打字即变、断句追加模式打完一句自动改、摇一摇模式摇一下就改。悬浮球支持拖动摆放、边缘吸附、位置持久记忆。

  3. 03

    自动改写并发送

    文本替换 → 前缀 → 后缀 → 随机尾缀，再走三级智能发送策略，一键到底，话就发出去了。

01

规则系统 · 优先级 1-100 防冲突

规则页采用列表模型，点「添加规则」即可按类型创建。每条规则都能设优先级 1-100（数字越大越先执行，同级按列表顺序，默认 50），从根上避免多条规则互相打架；还可开启「按等级全局执行」，让所有类型打散、严格按等级从大到小走一条流水线（例如让「替换」在后缀之后生效）。

  • 前缀 / 后缀 / 替换文本
  • 随机前缀·后缀（固定 / 不固定两种）
  • 优先级 1-100，数字越大越先执行
  • 按等级全局执行，杜绝规则冲突

常驻屏幕边缘，默认 56dp，拖动摆放、边缘吸附、位置记忆。柔光玻璃效果、5 秒空闲收成小圆点、大小与透明度实时可调，还能用任意图片作悬浮球头像（圆形裁剪）。

长按弹出：切换与管理规则预设、规则开关、行为与样式面板、立即变换并发送，以及设置 / 日志 / 终端 / 停止服务。

为指定应用单独绑定规则预设，切到该应用自动换套规则，未映射的应用沿用当前预设，另有「自动切换」总开关。

NekoType-OS V1 模块系统

导入 ZIP 模块（module.json 清单 + classes.dex 入口类），原生 DexClassLoader 在进程内加载、导入即生效。可声明文本变换 / 设置卡片 / 启动画面 / 菜单 / UI 覆盖；与宿主同权限，只装可信模块。

兼容性与输入保护

无障碍服务组件名伪装成系统「随选朗读」，绕过按类名屏蔽无障碍的应用（微信等，NyaNote / GKD 同款做法）。另有删除优化（删文字时暂停改写，停手约 0.5 秒再恢复）与语音输入 1 秒长停顿判定。

应用黑白名单

名单页列出全部已安装应用，可搜索、全选、清空。黑名单模式：名单内不自动篡改；白名单模式：只对名单内自动篡改。悬浮球手动点击始终不受限。

Mist 集成终端

复用 Termux 引擎的 PTY 真实终端，460+ 命令与 nekosay / nekomood / catbomb 等猫系命令，JetBrains Mono 等宽字体；字号 10-24sp、面板透明度、字体颜色均可调。

外观与六套主题

深色 / 浅色 / 跟随系统 / 星空 / 猫娘 / 前苏联（CCCP），可自定义任意图片作应用背景。前苏联主题为红旗红 + 鎏金 + 深褐底，构造主义红色斜带与红星图标，纯矢量任意分辨率不糊。

常见问题

先问后用，心里有数

需要 Root 吗？

不需要。基础模式仅需悬浮窗 + 无障碍权限即可使用；想要「静默修改」等增强功能，装一个 Shizuku（免 Root）就行。

微信能用吗？

微信目前还在适配中——它对无障碍改写有限制。NekoType 会自动尝试用 Shizuku 静默注入兜底，但部分场景可能仍需手动点悬浮球。

会读取我的聊天记录吗？

不会。NekoType 只读取当前聚焦输入框里的文本，不扫描、不记录、不存储聊天内容，处理完即丢弃。应用本身也没有任何联网能力。

篡改键盘模式会把后缀叠成「喵喵喵」吗？

不会。增量原文算法会记录你的真实输入和上次写回内容，只把新增部分并入原文后重新变换一次，连续打字后缀也只出现一次。

有几种运行模式？启动有动画吗？

四种互斥模式：悬浮球（点一下改写发送）、篡改键盘（打字即自动改）、断句追加（标点结尾才改）、摇一摇（摇一下就改）。启动时有图标弹性弹出 + 标题淡入的动画，1 秒进入首页。

耗电吗？

无障碍事件监听是系统级轻量回调，无轮询、无常驻网络，耗电可忽略。配合关闭电池优化白名单，后台常驻更稳。

如何彻底停用？

App 内关闭「启动服务」，并在系统设置中撤销无障碍 / 悬浮窗权限即可；卸载即清除全部本地数据，不留痕迹。
